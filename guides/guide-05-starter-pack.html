The starter pack

Four trusted directories, ten consensus picks across five categories, copy-paste install commands, one security caveat. As of May 2026. If you only read one chapter, this is the one that gets things on your machine.

04The one warning that matters
// READ THIS BEFORE INSTALLING COMMUNITY PLUGINS

Plugins can execute arbitrary code on your machine.

From Anthropic's own documentation: "Plugins and marketplaces are highly trusted components that can execute arbitrary code on your machine." A community plugin is, functionally, someone else's program running with your user permissions, with access to whatever Claude has access to.

Snyk's ToxicSkills research from February 2026 found 13.4% of publicly available skills had critical vulnerabilities, ranging from prompt injection vectors to outright credential exfiltration. The same risks apply to plugins, only larger because plugins can ship MCP servers and hooks too.

Practical defense: default to claude-plugins-official and the Anthropic-verified badge when possible. If you go to community marketplaces, prefer entries with security audit badges on claudemarketplaces.com or skills.sh. For anything that touches credentials (Gmail, GitHub, payment APIs), only install if you would trust the maintainer with the production API key it requires.
