Prompts, plugins, and links worth keeping.

The practical shelf. Where to find plugins and skills, the picks worth installing on day one, prompts you can copy as-is, slash commands worth building, and a short list of genuinely useful links. Accurate as of May 2026.

01 Where to find plugins & skills

Four directories, ranked by how much to trust them. Inside Claude Code, run /plugin to browse the official one without leaving the terminal.

Verified claude-plugins-official github.com/anthropics The official, Anthropic-managed directory — auto-installed when you launch Claude Code. The safe default for anything that touches credentials. Curated claudemarketplaces.com claudemarketplaces.com The largest third-party aggregator. Indexes skills, MCP servers, and full marketplaces with security-audit badges. Curated awesome-claude-plugins github.com/Chat2AnyLLM A traditional "awesome list", updated daily and sorted by use case — DevOps, code quality, documentation, git workflow, security. Aggregator aitmpl.com / plugins aitmpl.com Hubs skills, agents, commands, hooks, and plugins across Claude Code, Claude Desktop, and the Agent SDK. Good for cross-tool discovery.

03 Reusable prompts

Tested snippets you can copy and drop straight into your own prompts.

Explainer

Put in front of any question when the topic is new to you.

Explain this to me as if I'm smart but completely new to the field. Use one concrete analogy, define every term the first time you use it, and end with what I should learn next.
Coding

Get a plan before Claude writes a single line.

Before writing any code, outline your approach: the files you'll change, the order you'll do them in, and any trade-offs. Wait for my OK before you implement anything.
Code Review

Paste alongside a file or diff for a focused review.

Review this code for correctness, edge cases, and readability. Give findings as a short numbered list, most serious first. Don't rewrite it yet — just tell me what you'd change and why.
Debugging

When you're stuck and the obvious fixes failed.

Here's a bug I can't crack. Don't guess at fixes. First list the three most likely root causes, ranked by probability, then tell me exactly what to check or log to confirm which one it is.
Writing

Tighten any draft without losing the substance.

Cut this text by 30% without losing meaning. Remove hedging, filler, and repetition; keep the structure and every concrete detail. Show only the revised version.
Video & Lighting

Add to an image or video prompt for cinematic portrait lighting.

dramatic, natural side lighting from a window creates deep shadows and high contrast on the face. Warm color grading.
04 Slash commands worth building

A slash command is just a Markdown file in .claude/commands/. These five pay for themselves fast.

/commit

command

Reads your staged changes and writes a clean, conventional commit message — type, scope, and a tight summary.

→ .claude/commands/commit.md

/pr

command

Drafts a pull-request title and description from the branch diff, including a testing checklist.

→ .claude/commands/pr.md

/optimize

command

Profiles the file in focus and proposes concrete performance improvements, ranked by impact.

→ .claude/commands/optimize.md

/unit-test

command

Expands test coverage for the current file — happy paths plus the edge cases that usually get skipped.

→ .claude/commands/unit-test.md

/doc-refactor

command

Rewrites stale comments and docs so they match what the code actually does now.

→ .claude/commands/doc-refactor.md

06 Before you install community plugins
// read this first

Plugins can run arbitrary code on your machine.

From Anthropic's own documentation: plugins and marketplaces are highly trusted components that can execute arbitrary code on your machine. A community plugin is, functionally, someone else's program running with your permissions and Claude's access.

Practical defense: default to claude-plugins-official and the Anthropic-verified badge. On community marketplaces, prefer entries with security-audit badges. For anything touching credentials — Gmail, GitHub, payment APIs — only install it if you'd trust the maintainer with the production key it asks for.
