AI Glossary

This glossary is a Wikipedia-style reference covering the essential concepts, tools, and terminology needed to understand modern AI. Each topic links to related concepts, creating an interconnected knowledge base. Start anywhere — follow the links to build your understanding.

All Topics (A-Z)

  • Agent SDK — Development kit for building custom AI agents
  • AI Agent — AI systems that autonomously plan and execute tasks
  • AI Automation — Automated workflows using AI (n8n, Make, Zapier)
  • AI Model — The trained mathematical system inside AI applications
  • Applications — Software by platform: web, mobile, and desktop Web Apps Static Websites Full-Stack Apps Mobile Apps Desktop Apps
  • API — How software programs communicate with each other
  • Artificial Intelligence — The field of creating systems that perform human-like tasks
  • Claude — Anthropic's AI assistant and language model family
  • Claude Code — Agentic coding tool that lives in your terminal
  • Claude Design — AI-powered visual creation and prototyping tool
  • Claude Skills — Reusable instruction sets that extend Claude Code
  • Context Window — How much text an AI model can process at once
  • Deep Learning — Neural networks with many layers for complex patterns
  • Embedding — Numerical representation of meaning as vectors
  • Fine-tuning — Specializing a pre-trained model on specific data
  • Formats — How to structure text and data for AI Markdown XML JSON HTML
  • GitHub Pages — Free hosting for static sites, step-by-step deployment
  • Hallucination — When AI generates plausible but incorrect information
  • Human-in-the-Loop — Safety pattern for human oversight of AI actions
  • HTML vs Full Stack App — Static pages vs. complete software systems
  • IDE — Integrated Development Environment for writing code
  • Inference — When a trained AI model generates output
  • Large Language Model (LLM) — AI models trained on massive text to understand language
  • Machine Learning — Systems that learn patterns from data
  • Multi-Agent Systems — Multiple specialized AI agents coordinating on tasks
  • Model Context Protocol (MCP) — Open standard connecting AI to external tools and data
  • Natural Language Processing — Teaching computers to understand human language
  • Neural Network — Brain-inspired computing system of interconnected nodes
  • Prompt — The input you give to an AI model
  • RAG (Retrieval-Augmented Generation) — Grounding AI responses in retrieved sources
  • Routing — Classifying inputs to direct them down specialized paths
  • Temperature — Setting that controls AI response randomness
  • Technical SEO — Optimizing your site for search engines and AI discovery Meta Tags & OG Tags sitemap.xml robots.txt Google Search Console Structured Data Canonical URLs site.webmanifest
  • Token — The basic unit of text AI processes
  • Tool Use (Function Calling) — How AI models take actions by calling external functions
  • Training Data — The examples an AI model learns from
  • Transformer — The architecture behind all modern language AI
  • Workflow — Multi-step automated processes using AI
