01 Foundations — how AI learns and thinks
Artificial Intelligence The field of building systems that perform tasks needing human-like intelligence. Machine Learning Systems that learn patterns from data instead of following hand-written rules. Neural Network A brain-inspired computing system of interconnected nodes in layers. Deep Learning Neural networks with many layers that learn complex patterns. Transformer The architecture behind every modern language model. Natural Language Processing Teaching computers to understand and generate human language. Training Data The collection of examples an AI model learns from. Inference The phase when a trained model actually generates output. AI Model The trained mathematical system inside every AI application. Embedding A numerical representation of meaning as a vector of numbers. Fine-tuning Specializing a pre-trained model on focused, task-specific data.
02 Working with AI — using language models well
Large Language Model AI models trained on massive text to understand and generate language. Claude Anthropic's AI assistant and family of language models. Prompt The input you give an AI model — the instruction that drives it. Context Window How much text a model can hold in mind at once. Token The basic unit of text an AI model reads and writes. Temperature The setting that controls how random or creative responses are. Hallucination When AI generates plausible but factually wrong information. RAG Retrieval-Augmented Generation — grounding answers in real sources. Tool Use How models take action by calling external functions.
03 Claude Code — the agentic coding toolkit
Claude Code

An agentic coding tool that lives in your terminal and works through natural language. The hub of this section — everything below extends it.

Skills Slash Commands CLAUDE.md Subagents MCP Hooks Plugins Checkpoints CLI
Skills Reusable instruction sets that extend what Claude Code can do. Slash Commands Custom shortcuts for repeatable Claude Code tasks. CLAUDE.md & Memory Persistent project instructions and memory for Claude. Subagents Specialized AI helpers spawned for focused, parallel tasks. MCP An open standard connecting AI to external tools and data. Hooks Scripts that fire automatically on Claude Code events. Plugins Bundled skills, commands, agents, and MCP servers in one install. Checkpoints Save points in a session you can roll back to. CLI The command-line interface that runs Claude Code. Agent SDK A development kit for building custom agents on Claude's tools.
04 Agents & Automation — when AI takes action
AI Agent An AI system that autonomously plans and executes multi-step tasks. Multi-Agent Systems Several specialized agents coordinating to solve a problem. Workflow A predetermined sequence of steps the model executes. Routing Classifying inputs to direct them down specialized paths. Human-in-the-Loop A safety pattern that pauses AI for human review at key points. AI Automation Automated workflows powered by AI — n8n, Make, Zapier.
05 Building Apps — software you can ship
Applications

Software organized by platform — web, mobile, and desktop. The hub of this section.

Web Apps Static Websites Full-Stack Apps Mobile Apps Desktop Apps
Web Apps Interactive applications that run inside the browser. Static Websites Sites served as fixed files, with no server logic. Full-Stack Apps Complete systems with a frontend, backend, and database. Mobile Apps Native and cross-platform applications for phones. Desktop Apps Software installed and run directly on a computer. HTML vs Full-Stack Static documents compared with complete software systems. API The rules that let software programs talk to each other. IDE An Integrated Development Environment for writing code. Claude Design An AI-powered visual creation and prototyping tool. GitHub Pages Free hosting for static sites — a step-by-step deploy path.
06 Formats & Data — structuring text for AI
Formats

How to structure text and data so AI reads it cleanly. The hub of this section.

Markdown XML JSON HTML
Markdown Lightweight text formatting that survives AI preprocessing. XML Tag-based structure that Claude was specifically tuned to follow. JSON A lightweight key-value format for exchanging data. HTML The markup language that structures every web page.
07 Technical SEO — being found by search & AI
Technical SEO

Optimizing your site so search engines and AI can discover it. The hub of this section.

Meta Tags sitemap.xml robots.txt Structured Data Canonical URLs Search Console site.webmanifest
Meta Tags & OG Tags Page metadata for search results and social sharing. sitemap.xml A map of your site's pages for search crawlers. robots.txt Rules telling crawlers which pages they may access. Structured Data Machine-readable schema markup that explains your content. Canonical URLs Declaring the primary version of a page to avoid duplicates. Google Search Console Google's dashboard for monitoring search performance. site.webmanifest The config file that makes a site installable as an app.
