Web Apps

A web application is software that runs in a web browser. Users access it via a URL — no installation required. Web apps range from simple static pages (like this glossary) to complex full-stack systems (like Gmail or Notion).

Two Types of Web Apps

Static Websites — Frontend Only

Pre-built HTML, CSS, and JavaScript files served directly to the browser. No server-side processing happens per request. The content is the same for every visitor unless JavaScript modifies it client-side.

  • Examples: Blogs, portfolios, documentation, landing pages, this glossary
  • Hosting: Free on GitHub Pages, Netlify, Cloudflare Pages
  • Technologies: HTML, CSS, JavaScript

Full-Stack Applications — Frontend + Backend

A complete system with a user-facing interface, server logic, and a database. Can handle user accounts, payments, real-time data, and personalized experiences.

  • Examples: Gmail, Spotify Web, Amazon, ChatGPT
  • Hosting: Requires a server (Vercel, AWS, Railway, etc.)
  • Technologies: React/Vue + Node.js/Python + PostgreSQL/MongoDB

When to Use a Web App

  • You want instant access — no download or installation
  • You need to work across devices (phone, tablet, desktop)
  • You want easy updates (change the code, users get the new version immediately)
  • You don't need deep hardware access (camera, GPS, file system)
Web apps are the strongest category for AI-assisted development. AI can generate complete static websites from a single description, and for full-stack apps, AI handles UI components, API routes, and database schemas with high accuracy. Over 90% of professional developers use AI assistance for web development in 2026.

Layman's Analogy

A web app is like a restaurant you can walk into without a reservation. A static website is the menu posted on the window — same for everyone. A full-stack app is the full dining experience — you sit down, order, pay, and the kitchen (server) prepares something personalized for you.
