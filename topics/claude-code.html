Claude Code

Claude Code is an agentic coding tool by Anthropic that lives in your terminal, understands your codebase, and helps you code faster through natural language commands.

What is Claude Code?

Claude Code is a command-line interface (CLI) tool that brings Claude's AI capabilities directly into your development environment. Rather than switching between a chat window and your code editor, Claude Code works where developers already work — in the terminal and inside IDEs like VS Code and JetBrains.

It can read and edit files across your entire codebase, run commands, manage git workflows, execute tests, create pull requests, and build new features — all from natural language instructions.

How It Works

You install Claude Code via npm (npm install -g @anthropic-ai/claude-code), then run claude in any project directory. It indexes your codebase and lets you give it tasks like "fix the login bug" or "add dark mode to the settings page." Claude Code reads relevant files, makes changes, and can run your test suite to verify its work.

Developers control how much autonomy Claude Code has — from approving every file change to letting it work independently on routine tasks.

Key Features

  • Multi-file editing and refactoring
  • Git operations (commits, PRs, branch management)
  • Running tests and fixing failures
  • Extending with skills and MCP servers
  • Background agents for parallel tasks (Agent View, May 2026)

Configuration Files: CLAUDE.md, AGENTS.md & SKILL.md

Claude Code is steered by three kinds of Markdown files. They are easy to confuse because they all hold plain-English instructions — but they differ in when they load and which tools read them.

File What it is When it loads
CLAUDE.md Claude Code's project memory — coding conventions, build commands, architecture notes. The "how to work here" file. Always — read into context at the start of every session.
AGENTS.md A vendor-neutral, open standard for the same kind of project instructions — read by 60+ AI coding tools, not just Claude. Natively in tools that adopt the standard (Cursor, OpenAI Codex, GitHub Copilot, Windsurf…). Claude Code reads it only when imported via @AGENTS.md.
SKILL.md The defining file of a single skill — a reusable capability for one specific task, with YAML frontmatter plus instructions. On demand — only its name and description load at startup; the full file loads when the skill is triggered.

The core distinction is always-on context vs. on-demand capability. CLAUDE.md and AGENTS.md are standing instructions — rules that apply to everything Claude does in the project, so they sit in context the whole session. SKILL.md is a capability — a procedure for one kind of task, kept out of context until it is actually needed (a token-saving design called progressive disclosure).

CLAUDE.md vs. AGENTS.md is a question of ownership, not behavior. CLAUDE.md is Claude-specific. AGENTS.md is an open standard — now stewarded by the Agentic AI Foundation under the Linux Foundation — that more than 60 tools (Cursor, OpenAI Codex, GitHub Copilot, Windsurf, Gemini CLI, Zed and others) read natively as their default instructions file. Open a project in Cursor, or run Codex against a repo, and an AGENTS.md in the root is picked up automatically with no setup. Claude Code is the outlier: its native file is CLAUDE.md, and it honors AGENTS.md only when you import it with @AGENTS.md. That is why teams using several AI tools keep the shared rules in AGENTS.md and import that one file into CLAUDE.md — one source of truth, every tool.

Rule of thumb — if the guidance should apply to every task, it belongs in CLAUDE.md (or AGENTS.md). If it is a step-by-step procedure for one task you repeat occasionally, make it a skill with a SKILL.md.

Layman's Analogy

If Claude is like a knowledgeable assistant you chat with, Claude Code is like having that assistant sitting next to you at your desk, able to directly type on your keyboard, open your files, and do the actual work — not just tell you what to do, but do it for you while you supervise.

Real-World Example

Stripe deployed Claude Code to 1,370 engineers. One team completed a 10,000-line Scala-to-Java migration in four days — work that was estimated to take ten engineer-weeks manually.
