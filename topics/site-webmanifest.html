site.webmanifest

A site.webmanifest (or web app manifest) is a JSON file that tells browsers metadata about your website — its name, icons, theme color, and how it should behave when installed as an app on a user's device.

What is a Web Manifest?

The manifest is a small JSON file, typically placed in your project root, that describes your site to browsers. It's what enables the "Add to Home Screen" feature on mobile devices — turning your website into something that looks and feels like a native app (called a Progressive Web App or PWA).

You link to it from every HTML page: 

<link rel="manifest" href="/site.webmanifest">

What It Looks Like

{
  "name": "AI Glossary",
  "short_name": "AI Glossary",
  "description": "A comprehensive dictionary for understanding AI",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#0645ad",
  "icons": [
    {
      "src": "/images/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/images/icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}

Key Fields

  • name — Full name of your site (shown on splash screens)
  • short_name — Abbreviated name (shown under the app icon on home screens)
  • start_url — Which page opens when the app is launched
  • display — How the app looks: "standalone" (like a native app, no browser chrome), "browser" (normal tab), or "fullscreen"
  • theme_color — Color of the browser address bar on mobile
  • icons — App icons in multiple sizes (192px and 512px are the minimum)

Is It Necessary?

For SEO ranking: No. A web manifest has no direct impact on Google rankings. A missing manifest won't hurt your search position.

For user experience and professionalism: Yes. It signals a modern, well-built site. Without it:

  • Chrome on Android won't show an "Add to Home Screen" install prompt
  • Your PWA won't have a splash screen or proper icon
  • The browser address bar won't match your brand color

Priority: This is a Tier 3 item — nice to have, not critical. Focus on meta tags, sitemap, and robots.txt first.

Layman's Analogy

A web manifest is like a business card for your website that it hands to phones and browsers. It says: "Hi, my name is AI Glossary, my brand color is blue, here's my logo, and if you want to pin me to your home screen, open me like this." Without the business card, phones treat your site as just another anonymous web page.
