Context Window

The context window is the maximum amount of text (measured in tokens) that an LLM can "see" and consider at one time — including both the input and the output.

What is a Context Window?

Think of the context window as the AI's working memory. Everything the model needs to consider — your conversation history, system instructions, documents you've shared, and its own response — must fit within this window. Anything outside the window is invisible to the model.

Claude's context window is up to 1 million tokens (roughly 750,000 words or several full-length novels). Earlier models had much smaller windows — GPT-3 had only 4,096 tokens (about 3,000 words).

Why It Matters

  • Conversation length: Longer windows mean the AI remembers more of your conversation
  • Document analysis: Larger windows let you feed entire codebases or books to the model
  • Complex tasks: Multi-step reasoning needs more context to track all the pieces
  • Cost: More tokens in the context = higher API cost

Managing Context

When conversations exceed the context window, systems must decide what to keep and what to drop. Techniques include summarizing older messages, using RAG to fetch only relevant information, and prompt compression.

Layman's Analogy

The context window is like the size of your desk. A small desk (4K tokens) means you can only have one document open at a time. A huge desk (1M tokens) means you can spread out multiple books, notebooks, and reference materials simultaneously. The bigger the desk, the more information the AI can consider at once.
