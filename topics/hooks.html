Hooks

Hooks are automated actions that Claude Code runs in response to specific events during a session — such as before a file is written or after a command completes — enabling validation, formatting, and custom automation.

What are Hooks?

A hook ties an event to an action. You configure hooks in a settings file (settings.json), and Claude Code fires them automatically when the matching event occurs. Because they run deterministically — every time, no AI judgment involved — hooks turn "please remember to…" instructions into guarantees.

Hook Events

Claude Code supports roughly 29 events. The most commonly used:

EventFires when…Typical use
PreToolUseBefore a tool runsValidate or block a risky action
PostToolUseAfter a tool succeedsAuto-format code, scan for secrets
UserPromptSubmitA prompt is submittedValidate input before processing
SessionStartA session beginsSet up environment variables
StopClaude finishes respondingCheck that all tasks are complete

Hook Types

A hook's action can be a shell command (the default), an HTTP webhook, an LLM-evaluated prompt, an MCP tool call, or a subagent (agent). Command hooks receive event data as JSON on standard input and communicate back through exit codes — exit 0 to continue, exit 2 to block the operation.

What Hooks Are Good For

Common patterns include auto-formatting every file Claude edits, scanning new code for hardcoded secrets, blocking dangerous shell commands like rm -rf /, running tests before a commit, and sending the team a notification when a long task finishes. Hooks are how a team encodes its non-negotiable rules into the workflow itself.

Hooks execute arbitrary shell commands on your machine — use them at your own risk. Validate inputs, quote variables, skip sensitive files, and test a hook in isolation before relying on it.

Layman's Analogy

Hooks are like the automatic sensors in a modern car. You don't have to remember to turn on the headlights at dusk or lock the doors when you drive off — the car detects the event and does it for you, every time. Hooks do the same for your coding workflow: the trigger happens, the action follows, no one has to remember.
