sitemap.xml

A sitemap.xml is a file that lists every page on your website, telling search engines exactly what content exists, when it was last updated, and how important each page is relative to others.

What is a Sitemap?

A sitemap is a roadmap of your website written in XML format. You place it in your site's root directory (e.g., yoursite.com/sitemap.xml). Search engine crawlers (Googlebot, Bingbot) read this file to discover and understand the structure of your site.

Without a sitemap, search engines rely solely on following links between pages to discover content. If a page isn't linked from anywhere, it may never be found. A sitemap guarantees that every page is on the radar.

What It Looks Like

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://yoursite.com/</loc>
    <lastmod>2026-05-16</lastmod>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://yoursite.com/topics/claude.html</loc>
    <lastmod>2026-05-16</lastmod>
    <priority>0.8</priority>
  </url>
  <!-- ... one entry per page ... -->
</urlset>

Key Fields

  • <loc> — The full URL of the page (required)
  • <lastmod> — When the page was last updated (helps Google prioritize recrawling)
  • <priority> — Relative importance from 0.0 to 1.0 (hint to crawlers, not a ranking factor)
  • <changefreq> — How often the page changes (daily, weekly, monthly) — largely ignored by Google in 2026

How to Use It

  1. Create the file and place it at your site's root
  2. Reference it in your robots.txt: Sitemap: https://yoursite.com/sitemap.xml
  3. Submit it in Google Search Console → Sitemaps → enter the URL → Submit

Layman's Analogy

A sitemap is like the table of contents of a book. Without it, a reader (search engine) would have to flip through every page to find what's there. With a table of contents, they can immediately see every chapter (page), what it's called (URL), and jump straight to it. You also tell them which chapters were recently revised.
