robots.txt

robots.txt is a plain text file at the root of your website that tells search engine crawlers which pages they're allowed to visit and which they should skip.

What is robots.txt?

When a search engine's crawler (like Googlebot) first visits your site, the very first thing it checks is yoursite.com/robots.txt. This file contains rules about what the crawler can and cannot access. It's an honor system — crawlers voluntarily follow the rules, but it's not a security mechanism.

Every website should have a robots.txt file, even if it just says "everything is allowed." Without one, crawlers log a 404 error when they check — which is unnecessary noise.

What It Looks Like

# Allow all crawlers to access everything
User-agent: *
Allow: /

# Point to the sitemap
Sitemap: https://yoursite.com/sitemap.xml

Common Patterns

# Block all crawlers from a private folder
User-agent: *
Disallow: /admin/
Disallow: /private/

# Block a specific crawler (e.g., an AI training crawler)
User-agent: GPTBot
Disallow: /

# Allow Google but block everything else
User-agent: Googlebot
Allow: /
User-agent: *
Disallow: /

2026 Context: AI Crawlers

In 2026, robots.txt has gained new relevance because AI companies send their own crawlers to scrape web content for training data. Common AI crawler user-agents include:

  • GPTBot — OpenAI
  • ClaudeBot — Anthropic
  • Google-Extended — Google AI training
  • CCBot — Common Crawl

You can block AI training crawlers while still allowing search engine crawlers to index your site. This is a separate decision from SEO — it's about whether you want your content used to train AI models.

Important: robots.txt is Not Security

robots.txt does not prevent access — it's a polite request. Anyone can still visit any URL directly. For actual security, use authentication or server-side access controls. robots.txt is for controlling crawler behavior, not hiding content.

Layman's Analogy

robots.txt is like the "Staff Only" sign on a door in a store. Well-behaved visitors (crawlers) will respect it and not enter. But it's not a lock — anyone who really wants to can push through. It sets boundaries for polite guests, not protection against trespassers.
