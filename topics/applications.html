Applications (Software by Platform)

An application (app) is a software program built to perform tasks for users. Applications are categorized by where they run: in a web browser, on a phone, or on a desktop computer. Each platform has different technologies, trade-offs, and deployment methods.

AI has dramatically lowered the barrier to building applications across all platforms. Static websites and simple web apps are the easiest for AI to generate — a single prompt can produce a complete, working site. Mobile and desktop apps require more human guidance but AI handles boilerplate, UI layouts, and repetitive logic extremely well.

Which Platform Should You Choose?

  • Start with the web — lowest friction, no app store approval, works everywhere
  • Go mobile when you need push notifications, camera/GPS access, or offline capability
  • Go desktop when you need heavy computation, file system access, or OS-level integration

Many modern applications exist on multiple platforms. For example, Spotify has a web app, mobile app, and desktop app — all sharing some code but adapted to each platform's strengths.
