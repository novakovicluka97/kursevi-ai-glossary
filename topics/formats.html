Formats

Formats are the structured ways you package text and data when communicating with AI models. Choosing the right format directly affects how well the AI understands your input and how usable its output is.

Why Formats Matter for AI

LLMs process everything as text. But not all text is equal — structured text gets better results than unstructured walls of words. The format you choose determines:

  • How clearly the model understands your intent
  • How reliably it follows complex, multi-section instructions
  • Whether its output is usable by other systems (code, databases, automation tools)
  • Whether humans can also read and maintain the content

The Four Key Formats

Markdown

Plain-text formatting with simple symbols (#, **, -). The default for anything humans will also read: documentation, agent instructions (CLAUDE.md), RAG context, README files. Works well because LLMs saw massive amounts of Markdown in training data.

Use for: Documents, instructions, context that humans also read.

XML Tags

Paired tags like <instructions>...</instructions> that mark clear boundaries. The strongest structural signal for Claude specifically — Anthropic has tuned Claude to pay special attention to XML structure in prompts.

Use for: Production prompts, multi-section inputs, when the model must extract a specific section.

JSON

Key-value data format ({"name": "value"}). The universal standard for API communication and structured output. When you need AI to return data that code will process, JSON is the answer.

Use for: API calls, structured data output, automation configs, MCP messages.

HTML

The markup language of the web. AI models can both read and generate HTML. Used when the output needs to render in browsers — web pages, emails, reports, design exports.

Use for: Web output, rendered content, email templates, visual artifacts.

Practical Decision Guide

Situation Best Format
Writing a system prompt for Claude XML tags for sections + Markdown for content within
Agent instructions (CLAUDE.md, skills) Markdown
Feeding documents to RAG Markdown
Getting data for your app to use JSON (structured output)
Calling an AI API JSON
AI generating a web page or email HTML
Multi-section prompt where the model must isolate parts XML tags

Combining Formats

In practice, you often combine formats. A Claude system prompt might use XML tags to structure sections, Markdown for readable content within those sections, and instruct the model to output JSON. This is normal and encouraged: 

<instructions>
## Your Role
You are a data extraction assistant.

## Output Format
Return a JSON object with these fields:
- name (string)
- email (string)
- intent (string: "support", "sales", or "other")
</instructions>

<email>
{{user's email content here}}
</email>
