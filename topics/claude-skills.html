Claude Skills

Claude Skills are reusable instruction sets that extend Claude Code's capabilities — small markdown files that tell Claude how to perform specific tasks, triggered automatically by context or manually via slash commands.

What are Claude Skills?

A skill is a small folder containing a SKILL.md file with YAML frontmatter (name, description) and a markdown body with instructions that Claude follows when the skill is triggered. Skills let you teach Claude Code new behaviors without writing traditional code.

Skills can be auto-invoked (Claude detects when they're relevant and uses them automatically) or user-invoked (triggered by typing a slash command like /commit or /security-review).

Skills vs. Slash Commands

Slash commands are built-in, hardcoded operations (/clear, /help, /model) that do one specific thing without AI reasoning. Skills are prompt-based — they give Claude detailed instructions to orchestrate complex work using its tools. Skills are customizable and extensible; slash commands are fixed.

SKILL.md vs. CLAUDE.md

A SKILL.md is easy to confuse with a CLAUDE.md file, since both are Markdown instructions. The difference is timing: CLAUDE.md is always loaded — standing rules for the whole project — while a skill's SKILL.md loads only when triggered. Put always-relevant guidance in CLAUDE.md; put a procedure for one occasional task in a skill. See Claude Code for the full comparison, including the vendor-neutral AGENTS.md standard.

How to Create a Skill

# .claude/skills/my-skill/SKILL.md

---
name: security-review
description: Reviews code for security vulnerabilities
---

Review the code for OWASP Top 10 vulnerabilities.
Check for SQL injection, XSS, and auth issues.
Report findings with severity levels.

Layman's Analogy

Think of skills like recipe cards for a chef. The chef (Claude) already knows how to cook, but the recipe card gives specific instructions for a particular dish. You can write new recipe cards anytime, and the chef will follow them. Some recipes the chef pulls out automatically when they see the ingredients; others you have to ask for by name.
