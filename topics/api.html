API (Application Programming Interface)

An API is a set of rules and protocols that allows different software programs to communicate with each other — like a waiter taking orders between you (the application) and the kitchen (the service).

What is an API?

An API defines how one piece of software can request services from another. When you use a weather app, it calls a weather API to get the forecast data. When a developer uses Claude in their application, they call Anthropic's API to send prompts and receive responses.

APIs are the glue of modern software. They allow different systems — built by different companies, in different languages, running on different servers — to work together seamlessly.

APIs in AI

AI companies provide APIs so developers can integrate AI models into their own applications. Instead of building and training your own model (which costs millions), you call an API and pay per use. Anthropic's Claude API, OpenAI's API, and Google's Gemini API are the main ones.

The Model Context Protocol is itself an API standard — it defines how AI agents communicate with external tools and data sources.

REST APIs

Most web APIs use REST (Representational State Transfer) — a pattern where you send HTTP requests (GET, POST, PUT, DELETE) to specific URLs and receive JSON data back. For example, sending a POST request to api.anthropic.com/v1/messages with a prompt returns Claude's response.

Layman's Analogy

An API is like a restaurant menu. The menu (API documentation) tells you what you can order (available operations). You tell the waiter (API request) what you want. The kitchen (server) prepares it, and the waiter brings back your food (API response). You don't need to know how the kitchen works — just how to read the menu.
