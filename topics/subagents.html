Subagents

A subagent is a specialized AI assistant that Claude Code delegates a task to — running in its own context window, with its own instructions and its own restricted set of tools.

What is a Subagent?

When the main Claude Code session hits a focused job — reviewing code, hunting a bug, writing tests — it can hand that job to a subagent instead of doing it inline. The subagent starts with a clean slate, receives only the context it needs, does the work, and returns a distilled result. The main conversation never sees the subagent's intermediate steps.

Why Delegate?

BenefitWhat it means
Context preservationThe subagent's exploration doesn't clutter the main conversation's context window
Specialized expertiseA custom system prompt tunes it for one domain — security, testing, debugging
Tool controlA read-only reviewer can be denied write access entirely
ParallelismSeveral subagents can work on different parts of a task at once

Built-in and Custom Subagents

Claude Code ships with built-in subagents like Explore (fast, read-only codebase search), Plan (research for plan mode), and general-purpose (complex multi-step work). You can also define your own as Markdown files in .claude/agents/, each with YAML frontmatter setting its name, description, allowed tools, and model. The /agents slash command creates and manages them interactively.

Subagents vs. Multi-Agent Systems

Subagents are one form of a multi-agent system. The defining trait is the parent–child relationship: a subagent is a delegated subtask that returns a result to its parent. This differs from "agent teams," where independent agents work side by side and message each other directly. Subagents also cannot spawn their own subagents — delegation is one level deep.

Layman's Analogy

A subagent is like a specialist a general contractor calls in. The contractor doesn't rewire the house personally — they bring in an electrician, hand over just the relevant blueprints, and get back a finished job. The electrician's mess of tools and trips to the truck never crowds the contractor's own workspace.
