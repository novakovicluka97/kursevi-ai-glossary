AI Agent

An AI agent is an AI system that can autonomously plan and execute multi-step tasks — not just answer questions, but take actions in the world to achieve goals.

What is an AI Agent?

A regular chatbot responds to one message at a time. An AI agent goes further: given a goal, it breaks it down into steps, decides which tools to use, executes actions, observes results, and adjusts its plan — all with minimal human supervision.

For example, if you tell an agent "book me a flight to London next Tuesday under $500," it would search flights, compare options, fill in your details, and complete the booking — making decisions along the way.

Agent Components

  • Brain: An LLM that reasons and makes decisions
  • Tools: Capabilities like web browsing, file access, code execution (often via MCP)
  • Memory: Ability to remember context across steps
  • Planning: Breaking goals into sub-tasks
  • Loop: Observe → Think → Act → Repeat until goal is achieved

Examples

Claude Code is an AI agent for software development. It reads code, plans changes, edits files, runs tests, and commits — all autonomously. Other examples include customer support agents, research agents, and data analysis agents built with the Agent SDK.

Layman's Analogy

A regular AI is like a librarian — you ask a question, they give you an answer. An AI agent is like a personal assistant — you say "plan my vacation," and they research destinations, compare prices, book hotels, arrange transport, and send you the itinerary. They don't just inform; they act.
