AI Agent

An AI agent is an AI system that can autonomously plan and execute multi-step tasks — not just answer questions, but take actions in the world to achieve goals, dynamically deciding its own path.

What is an AI Agent?

A regular chatbot responds to one message at a time. An AI agent goes further: given a goal, it breaks it down into steps, decides which tools to use, executes actions, observes results, and adjusts its plan — all with minimal human supervision.

For example, if you tell an agent "book me a flight to London next Tuesday under $500," it would search flights, compare options, fill in your details, and complete the booking — making decisions along the way.

Agent vs Workflow: When to Use Which

The key distinction: in an agent, the model decides the path. In a workflow, you define the path.

  • Use a workflow when the steps are predictable and the same every time (translating reviews, classifying emails, generating reports)
  • Use an agent when the task requires ongoing judgment, the path is unknown upfront, or you need adaptive problem-solving

When agents pay off: Imagine the task is "investigate why customer complaints spiked this week." The agent might query the database, notice a pattern in shipping delays, check the logistics provider's status page, cross-reference with a recent deployment, and read related Slack messages. You cannot predefine these steps because you don't know where the data will lead. That's when you need an agent.

Agent Components

  • Brain: An LLM that reasons and makes decisions
  • Tools: Capabilities like web browsing, file access, code execution (often via MCP) — see Tool Use
  • Memory: Ability to remember context across steps
  • Planning: Breaking goals into sub-tasks
  • Tool-Use Loop: Observe → Think → Act → Get Result → Repeat until goal is achieved (see Tool Use for details)

Single Agent vs Multi-Agent

Most production agents are single agents with many tools. One LLM with access to search, databases, file systems, and APIs can handle remarkably complex tasks.

Multi-agent systems add coordination overhead — only use them when a single agent's context window is overwhelmed, when subtasks need different permission levels, or when you need distinct expertise domains that would conflict in one system prompt.

Examples

Claude Code is an AI agent for software development. It reads code, plans changes, edits files, runs tests, and commits — all autonomously, deciding what to do based on what it finds. Other examples include customer support agents, research agents, and data analysis agents built with the Agent SDK.

Layman's Analogy

A regular AI is like a librarian — you ask a question, they give you an answer. An AI agent is like a personal assistant — you say "plan my vacation," and they research destinations, compare prices, book hotels, arrange transport, and send you the itinerary. They don't just inform; they act. And crucially, they decide the order themselves based on what they find — they don't follow a script.
