Agent SDK

The Claude Agent SDK is a development kit that gives programmers the same tools, agent loop, and context management that power Claude Code — programmable in Python and TypeScript to build custom AI agents.

What is the Agent SDK?

An SDK (Software Development Kit) is a collection of tools and libraries that helps developers build applications. The Claude Agent SDK specifically helps developers build AI agents — autonomous programs that can read files, run commands, edit code, browse the web, and complete multi-step tasks.

Instead of building all the infrastructure from scratch (tool execution, conversation management, safety checks), the Agent SDK provides these as ready-to-use building blocks. You focus on defining what your agent should do; the SDK handles how it runs.

Built-in Capabilities

  • File reading, writing, and searching
  • Running bash commands
  • Code editing
  • Web browsing
  • MCP server connections
  • Conversation and context management

Use Cases

Developers use the Agent SDK to build custom automation: code review bots, data analysis pipelines, content generation systems, CI/CD agents that fix failing tests, customer support agents, and any workflow that benefits from an AI that can think and act autonomously.

Layman's Analogy

If Claude Code is a fully assembled robot that helps you code, the Agent SDK is the robot parts kit — motors, sensors, circuit boards — that lets you build your own custom robot for whatever job you need. You get all the same powerful components, but you decide how they're assembled.
