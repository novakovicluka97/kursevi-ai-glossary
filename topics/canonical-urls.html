Canonical URLs

A canonical URL is a tag that tells search engines "this is the official version of this page" — preventing duplicate content problems when the same content is accessible at multiple URLs.

The Problem

The same page can often be reached via multiple URLs:

  • https://yoursite.com/article
  • https://yoursite.com/article/ (trailing slash)
  • https://yoursite.com/article?ref=twitter (with tracking parameters)
  • http://yoursite.com/article (HTTP vs HTTPS)
  • https://www.yoursite.com/article (www vs non-www)

Google sees these as five different pages with identical content. This splits your SEO value across all of them instead of concentrating it on one. Canonical tags solve this.

The Solution

<link rel="canonical" href="https://yoursite.com/article">

Add this to the <head> of every page. It tells search engines: "Regardless of how you arrived at this page, the official URL is this one. Give all the SEO credit here."

2026 Context

Canonical URLs are increasingly important because AI search engines (Google AI Overviews, ChatGPT, Perplexity, Claude) also rely on canonical signals to determine which version of a page to ingest and cite. Without clear canonicalization, AI systems might cite a URL with tracking parameters — or worse, ignore your page entirely because it looks like a duplicate.

Rules

  • Every page should have a canonical tag, even if it only has one URL (self-referencing canonical)
  • Always use the HTTPS version
  • Pick one style (www or non-www) and stick with it
  • Pick one style (trailing slash or not) and stick with it
  • The canonical URL should be the fully qualified URL (including https://)

Layman's Analogy

Imagine a book published under three different covers with slightly different titles, but the same content inside. Libraries would catalog it as three separate books, splitting reviews and lending records. A canonical URL is like telling libraries: "These are all the same book — please file everything under this one ISBN." All the "credit" consolidates under one entry.
